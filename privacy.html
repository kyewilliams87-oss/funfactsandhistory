Privacy policy

Last updated: 27 October 2026

Reel bot is a personal tool run by its owner. It is not offered to the public.

What it accesses

With the owner's permission, Reel bot uses the YouTube Data API with one permission: uploading videos to the owner's own YouTube channel (youtube.upload). It does not read, collect or store any other Google account data, and it accesses no data about other people.

What it stores

The sign-in token that lets it upload is stored only on the owner's own server. It is never shared or sold. The videos it makes are stored on that server until they are uploaded or deleted.

Use of Google data

Reel bot's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
